# UCAN Lesson 05

Static learner lesson implementing `UCAN-L05-CEC-002` on `develop`.

- 11 learner routes (`R01`–`R11`); final route `R11`.
- Local state namespace: `ucan.lesson05.v2`; compatible v1 Portfolio data is migrated once.
- The approved L05-A01 PNG and local pdfmake runtime are retained unchanged.
- The practical card contains 9 required and 1 conditional field. Reset preserves the card; deletion is separate.
- Creator preview is available only with `?qa=1` and remains in memory.

No build step or CDN is required. Open `index.html` through a static HTTP server for local verification.
